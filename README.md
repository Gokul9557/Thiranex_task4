# Sales Data Preprocessing and Business Intelligence Dashboard

## Thiranex Internship | Task 4

### Introduction

Accurate data is essential for effective business intelligence and decision-making. This project demonstrates a systematic data preprocessing workflow using Microsoft Power BI Desktop, followed by the development of an interactive sales performance dashboard.

The implementation emphasizes improving data reliability, maintaining consistent formatting, and transforming raw business records into an analysis-ready dataset.

### Project Goals

The primary goals of this task are:

- Examine raw sales data for quality issues.
- Eliminate redundant records.
- Address missing and invalid entries.
- Standardize categorical and textual information.
- Apply appropriate data type conversions.
- Build a dashboard to visualize key business metrics.

### Technology Stack

| Technology | Purpose |
|---|---|
| Power BI Desktop | Business intelligence reporting |
| Power Query | Data preprocessing and transformation |
| DAX | Business metric calculations |
| CSV | Dataset storage and import |
| GitHub | Project documentation and version control |

### Data Source

The analysis is performed using a retail Superstore dataset containing transactional and customer information.

The dataset includes order details, shipping dates, product categories, customer segments, geographical locations, sales amounts, quantities, and profit values.

### Workflow

#### Phase 1: Data Acquisition

Loaded the source dataset into Microsoft Power BI Desktop and accessed Power Query Editor to begin the transformation process.

#### Phase 2: Data Profiling

Enabled the built-in data profiling features to evaluate:

- Column quality
- Value distribution
- Missing entries
- Data type consistency
- Invalid records

#### Phase 3: Data Cleaning

Performed essential preprocessing operations, including:

- Removing duplicate records.
- Handling null and blank values.
- Correcting data type mismatches.
- Trimming unnecessary whitespace.
- Removing non-printable characters.
- Standardizing text capitalization.

#### Phase 4: Data Transformation

Organized the cleaned data into consistent formats suitable for analytical reporting.

Validated numerical fields, date columns, and categorical attributes before loading the transformed dataset into the Power BI data model.

#### Phase 5: Dashboard Design

Developed a sales performance dashboard featuring:

**KPI Indicators**
- Total Number of Records
- Total Sales Revenue
- Total Profit

**Analytical Visualizations**
- Regional Sales Comparison
- Product Category Sales Distribution
- Customer Segment Filtering

The dashboard supports interactive exploration of retail business performance.

### Key Learning Outcomes

Through this project, practical knowledge was gained in:

1. Data quality evaluation and profiling.
2. ETL operations using Power Query.
3. Duplicate detection and data validation.
4. Data standardization and formatting.
5. Building interactive Power BI reports.
6. Presenting business information through visual analytics.
